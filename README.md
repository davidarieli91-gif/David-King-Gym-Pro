## 🌟 Ключевые возможности

### 🏋️‍♂️ 1. Управление тренировочным процессом
- **Конструктор сплитов:** Поддержка Full Body, Upper/Lower, Push-Pull-Legs (PPL), AB, ABCD, ABCDE и классических объемных сплитов.
- **Биомеханический авто-сортировщик (Auto-Arrange):** Автоматическая расстановка упражнений по золотому стандарту (Базовые многосуставные $\rightarrow$ Изолирующие $\rightarrow$ Кор / Заминка).
- **Fitbod-подобная карта восстановления мышц (Recovery Map):** Математический расчет мышечного утомления на основе экспоненциального затухания ($\tau = 3.0$ дня) с интерактивной векторной SVG-подсветкой мышечных групп.
- **Живой трекинг тренировки (Live Workout):** Секундомер, таймер отдыха между сетами, классификация подходов (`warmup`, `normal`, `dropset`, `failure`), фиксация RPE/RIR и защита от потери данных (автосохранение драфта каждые 30 сек).

---

### 🥗 2. Нутрициология и диетология
- **Гибридный расчет обмена веществ:** Расчет BMR по связке 70% Katch-McArdle + 30% Mifflin-St Jeor с поправкой на процент жира и 5 уровней физической активности.
- **Аминокислотный скор и профиль белка:** Глубокий анализ содержания BCAA (лейцин, изолейцин, валин) и незаменимых аминокислот.
- **База продуктов (3000+ наименований):** Включает международные базы USDA, Open Food Facts и израильские продукты с штрихкодами.

---

### 🖨️ 3. Движок калиброванной печати PageGym (A4 Print Engine)
- Генерация и распечатка готовых тренировочных бланков для зала с разбивкой на 10 мышечных секторов.
- Интерактивная калибровка сетки в миллиметрах (mm) для печати прямо на фирменных клубных бланках.

---

### 🧠 4. ИИ-Генератор программ (AI Pro & Auto)
- Поддержка подключения любых OpenAI-совместимых эндпоинтов (OpenAI, Claude, GLM, OpenRouter, Ollama, LM Studio) по модели BYOK (Bring Your Own Key).
- Автоматический расчет нагрузки и генерация персонализированных планов под цели клиента.

---

### 🔒 5. 100% Приватность и Offline-First (Zero-Backend)
- Все данные клиентов, замеры и история хранятся исключительно в вашем браузере (IndexedDB `fitness_crm_db` v9).
- Автономная работа в подвальных залах без интернета через Service Worker v16.
- Защита доступа паролем с хэшированием PBKDF2-HMAC-SHA256.

---

## 🎨 Темы оформления и локализация
- **20 встроенных тем:** Тёмные, светлые, приглушенные полутона и анимированные темы с фоновыми частицами.
- **Glassmorphism & Fluid Scales:** Настройка масштаба шрифтов (от A5− до A10+) и модальных окон.
- **3 языка и поддержка RTL:** Полная локализация интерфейса на Русский (RU), Английский (EN) и Иврит (HE) с автоматическим зеркалированием сетки.

## 🚀 Быстрый старт

### Вариант 1: Запуск прямо в браузере (Без установки)
Просто откройте [GitHub Pages](https://davidarieli91-gif.github.io/David-King-Gym-Pro/) на компьютере, планшете или смартфоне и нажмите «Установить приложение» (PWA).

### Вариант 2: Локальный запуск
```bash
# Клонируйте репозиторий
git clone https://github.com/davidarieli91-gif/David-King-Gym-Pro.git

# Откройте index.html в любом современном браузере или запустите локальный сервер:
npx serve .
```

## 📂 Структура проекта

```
├── index.html                 # Redirect на fitness-crm.html
├── fitness-crm.html           # Полный исходный монолит приложения
├── client.html                # Клиентский портал (PWA, QR-доступ)
├── exercise-db.json           # База из 1660+ упражнений (EN/RU/HE, анимации)
├── food-db.json               # База продуктов с нутриентами и штрихкодами
├── sw.js                      # Service Worker для работы офлайн
├── manifest.json              # PWA манифест для установки на телефон/ПК
├── data/                      # Исходные CSV и демо-бэкап клиентов
├── scripts/                   # Скрипты нормализации данных
├── reports/                   # Аудит базы данных
└── images/                    # Иллюстрации упражнений
```
